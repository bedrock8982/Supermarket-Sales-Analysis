# Supermarket Sales Analysis

## Overview

This project analyzes a supermarket sales dataset using Python. The objective is to explore the dataset, perform statistical analysis, and visualize relationships between store characteristics and sales performance.

---

## Objectives

- Load and explore the supermarket dataset
- Clean and prepare the data for analysis
- Analyze store sales and customer trends
- Visualize relationships between different variables
- Draw meaningful conclusions from the data

---

## Technologies Used

- Python
- Pandas
- Matplotlib
- Google Colab

---

## Dataset Information

The dataset contains information about supermarket stores, including:

- Store ID
- Store Area
- Items Available
- Daily Customer Count
- Store Sales

---

## Analysis Performed

The following analyses were carried out:

- Dataset exploration
- Missing value analysis
- Store sales analysis
- Daily customer count analysis
- Store area analysis
- Items available analysis
- Relationship between store area and sales
- Relationship between customer count and sales
- Relationship between items available and sales

---

## Visualizations

The project includes the following visualizations:

- Store Sales Distribution
- Daily Customer Count Distribution
- Store Area vs Store Sales
- Daily Customer Count vs Store Sales
- Items Available vs Store Sales

---

## Key Findings

- The dataset contains 896 supermarket store records.
- The dataset has no missing values.
- Store sales vary across different stores.
- Customer count and store sales show a positive relationship.
- Store area and the number of available items may influence sales performance.
- Data visualization helps identify patterns and relationships within the dataset.

---

## Conclusion

This project demonstrates how Python can be used to analyze supermarket sales data. Using Pandas for data manipulation and Matplotlib for visualization, the dataset was explored to understand sales trends and the relationships between store area, customer count, available items, and overall sales. The project provides practical experience in exploratory data analysis and business data visualization.
